The following is the first part of my visit to Warsaw in April (sorry for the super late post!). As part of the visit, I also visited [Visuality](http://www.visuality.pl/) and spent an evening there giving a presentation and discussing the topics afterwards for a long time. We capped it off some board games ;) I had a great time and the discussions were super interesting. The talk is a reworked old goldie ("Code is read many more times than written" / "Optimizing for Readability") and is about readable code and keeping readable code. It's evolved as I evolve - I learn new things, assign differing importance to different topics and discover entirely new important topicss. You can view the slides here or on [speakerdeck](https://speakerdeck.com/pragtob/code-comments-concepts-comprehension-conclusion), [slideshare](https://www.slideshare.net/PragTob/code-comments-concepts-comprehension-conclusion) or [PDF](https://pragtob.wordpress.com/wp-content/uploads/2017/06/optimizing_for_readability_warsaw.pdf "optimizing_for_readability_warsaw").
