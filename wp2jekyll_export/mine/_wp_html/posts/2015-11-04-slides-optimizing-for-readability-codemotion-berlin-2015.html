Yesterday I gave a talk at Codemotion Berlin, it was "Optimizing For Readability" - an updated version of my "Code is read many more times than written". It features new insights and new organizational practices to keep the code base clean and nice. Abstract: What do software engineers do all day long? Write code? Of course! But what about reading code, about understanding what’s happening? Aren’t we doing that even more? I believe we do. Because of that code should be as readable as possible! But what does that even mean? How do we achieve readable code? This talk will introduce you to coding principles and techniques that will help you write more readable code, be more productive and have more fun!
